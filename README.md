# 🔐 Password Generator

A simple and useful password generator application developed using Python.

With this application, you can create random passwords based on your preferences. You can set the password length, choose which character types to use, and block characters you do not want to include.

## Features

- Set minimum and maximum password length
- Lowercase letter option
- Uppercase letter option
- Number option
- Symbol option
- Block unwanted characters
- Generate random passwords
- Show password strength level
- Copy generated passwords
- Dark themed interface

## Technologies Used

- Python
- CustomTkinter
- Pyperclip

## Installation

First, download the application and open the project folder. Then open the terminal in the folder and install the required packages.

To install the required packages:

```bash
pip install -r requirements.txt
```

After that, run the program from the terminal.

To start the application:

```bash
python main.py
```

## Usage

After opening the program:

1. Enter the minimum and maximum password length.
2. Select the character options you want to use.
3. Enter the characters you do not want to include.
4. Click the generate password button.
5. Copy and use your generated password.
